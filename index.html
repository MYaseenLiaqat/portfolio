CASE 01 · APPLIED AI / RESEARCHFlagship

AI Learning Research

Problem. Build an experimental learning platform where AI can support a learner without silently becoming the learner, while keeping conditions reproducible enough for research.

01

Freeze experimental provenance. Learner condition, prompt version, model/provider identifiers, module version, and AI cap are persisted so mutable runtime settings do not rewrite the study history.

02

Control assistance. AI access is condition-aware, attempts are ownership-checked, supported sessions expire, and interaction count is capped at eight.

03

Grade deterministically. Code runs in a fresh namespace with an explicit result variable, while automated tests cover access, submission, scheduling, and prompt integrity.

5 study phases8 AI turns max20m supported phase15+ integrity tests
