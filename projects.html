CASE 01 · APPLIED AI / RESEARCHAI Learning ResearchControlled assistance, frozen provenance, deterministic grading, and research integrity.Open case study +

Problem. Build an experimental learning platform where AI can support a learner without silently becoming the learner, while keeping study conditions reproducible.

01

Freeze provenance. Learner condition, prompt version, model/provider identifiers, module version, and AI cap are persisted instead of inherited from mutable runtime settings.

02

Control assistance. AI access is condition-aware, attempts are ownership-checked, supported sessions expire, and interaction count is capped.

03

Grade deterministically. Code runs in a fresh namespace with an explicit result variable, while automated tests cover access, submission, scheduling, seed data, and prompt integrity.

CASE 02 · FULL-STACK AIReflctA product-first AI architecture connecting application state, retrieval, and inference.Open case study +

Problem. Put journaling, habits, goals, and an AI companion into one product without treating the AI layer as a disconnected demo.

01

Keep product state central. Supabase provides persistent application data that the experience is built around.

02

Add retrieval before inference. LlamaIndex provides relevant application context before the model generates a response.

03

Ship the full loop. Next.js handles the product surface and Groq supplies the inference layer.
